# MoneyLog 🐷

매일 쓰는 돈을 가볍게 기록하려고 만든 개인용 가계부 앱입니다. 지출을 빠르게 남기고, 캘린더로 한눈에 확인하고, 그날그날 있었던 일도 메모로 같이 남길 수 있게 만들고 있습니다.

## 주요 기능

- **지출 등록**: 커스텀 키패드로 금액을 입력하고 카테고리를 골라 빠르게 기록
- **월별 지출 목록**: 년/월을 골라서 보거나, 화면을 좌우로 스와이프해서 이전 달·다음 달로 바로 이동
- **캘린더**: 날짜별 지출 내역을 달력에서 확인, 선택된 날짜를 한 번 더 탭하면 그날의 메모 작성창이 열림
- **일별 메모**: 메모가 있는 날짜는 캘린더에 📝 표시, 메모 목록 화면에서 월별로 모아보고 바로 수정·삭제 가능 (여기서도 좌우 스와이프로 달 이동)
- 모든 데이터는 기기 안(Room/SQLite)에 저장되어 인터넷 연결 없이도 사용 가능

## 기술 스택

- Kotlin, Android (AppCompat)
- Room (SQLite)
- Kotlin Coroutines
